# Air_pollution_health_GS
Generation of pollution exposure estimates and associations with incident disease in Generation Scotland

Code for "Air pollution exposure in Generation Scotland and long-term health outcomes".

This includes: 
- extraction of pollution data from the EMEP4UK atmospheric chemistry transport model and assessment of Scotland-wide patterns,
- generation of pollution exposure estimates over different time frames for Generation Scotland participants
- association analyses with incident disease over ~ 18years of follow-up
